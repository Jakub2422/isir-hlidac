# ISIR Reality MSK

Existující aplikace pro přehled insolvenčních nemovitostí, dražeb a prodejů.

Aktuální provoz: https://isir-reality-msk-jakub.posusnanickuv.chatgpt.site

Zdrojová aplikace používá Next.js 16, React 19, Vinext a Cloudflare D1. Převod do tohoto repozitáře probíhá z existující verze; nejde o nový projekt. Supabase a Vercel zatím nejsou zapojené do provozu.
